# اتو مدیران (AUTO MODIRAN) — نمایشگاه خودرو

صفحه‌ها به مسیرهای جدا تقسیم شده‌اند: خانه با تیزر و نمایش سه‌بعدی، موجودی، جزئیات هر خودرو، فروش، اقساط، مقایسه، درباره ما، شعبه‌ها، تماس و ورود. تیزر سه‌بعدی فقط در خانه اجرا می‌شود؛ مدل سه‌بعدی هر خودرو فقط در مسیر `/vehicle/<شناسه>` بارگذاری می‌شود. هنگام ورود و جابه‌جایی صفحه، لودینگ برند اتومدیران نمایش داده می‌شود.

## اجرا

```sh
npm install
npm run dev
```

آدرسی را که در ترمینال نشان داده می‌شود در Chrome باز کنید. برای نسخه نهایی: `npm run build` (خروجی در پوشه `dist`).

- نمونه آدرس جزئیات خودرو: `/car/DEMO-001`.
- نمونه آدرس نمایش سه‌بعدی: `/vehicle/tiggo8pro`.
- هاست نهایی باید مسیرهای ناشناخته را به `index.html` برگرداند تا آدرس مستقل هر صفحه با بازکردن مستقیم یا تازه‌سازی کار کند.

## ویرایش

- **مشخصات، امکانات، رنگ‌ها، نام سایت، پلاک‌ها:** `src/cars.js`
- **موجودی خودروهای نمایشگاه:** از ERP (بخش «اتصال به ERP»)؛ بدون ERP از `src/inventory.js`. مشخصات اولیه از فایل‌های `agahi*.png` پوشه‌های `public/cars` وارد شده‌اند؛ نام خودرو، قیمت، سال ساخت، کارکرد، شعبه و مسیر عکس‌ها در همین فایل قرار دارد.
- **معرفی سینمایی:** آرایه `INTRO` بالای `src/Viewer.jsx` — برای هر ماشین یک بخش با نماهای خودش (مدت، حرکت دوربین، نور، رنگ ماشین). ماشین آخر همان ماشینی است که بعد از معرفی روی صفحه می‌چرخد.
- **لوگو:** `src/Logo.jsx` (شکل لوگو در `src/logoPath.js`، تبدیل‌شده از `logo.png`). نسخه بزرگ طلایی: `logo-gold.png`.
- **پلاک:** تصویر `public/plate.jpg` (اندازه ۲۰۴۸×۶۶۰). هر تصویر دیگری با همین نسبت را می‌توانید جایگزین کنید.

## افزودن ماشین جدید

1. فایل `.glb` را در `models-source` بگذارید.
2. پلاک و چراغ جلو را جدا کنید، سپس فشرده کنید:
   ```sh
   npm i -D @gltf-transform/core @gltf-transform/extensions @gltf-transform/cli draco3dgltf
   node scripts/plates.mjs models-source/car.glb tmp1.glb
   node scripts/headlights.mjs tmp1.glb tmp2.glb
   npx gltf-transform optimize tmp2.glb public/models/car.glb --compress draco --texture-compress webp --texture-size 1024 --simplify false --palette false
   ```
   `headlights.mjs` محل چراغ‌ها را چاپ می‌کند (front, y, side) — همان اعداد را در `lamp` در `src/cars.js` بنویسید.
3. یک بخش جدید در آرایه `cars` در `src/cars.js` اضافه کنید.

## افزودن خودرو و عکس به موجودی

1. برای خودرو یک پوشه در `public/cars/` بسازید؛ برای نمونه `public/cars/demo-001/`.
2. عکس‌های خود خودرو را در آن بگذارید (مثل `front.jpg`, `back.jpg`, `interior.jpg`). فایل‌های توضیحات را با نام `agahi.png`, `agahi1.png` یا `agahi2.png` در همان پوشه نگه دارید تا برای ورود اطلاعات مرجع باشند؛ این اسکرین‌شات‌ها به‌عنوان عکس گالری نمایش داده نمی‌شوند.
3. یک مدل در `CATALOG_CARS` و یک رکورد موجودی در `inventory` در `src/inventory.js` اضافه کنید. مسیر عکس‌ها را در `photos` بنویسید:
   ```js
   photos: ['/cars/demo-001/front.jpg', '/cars/demo-001/back.jpg'],
   ```
4. گالری خودروها هر چهار ثانیه بین عکس‌ها جابه‌جا می‌شود. برای یک عکس ثابت، فقط یک مسیر بنویسید. عکس افقی با فرمت WebP سریع‌تر بارگذاری می‌شود.

## افزودن برگه کارشناسی رنگ

برای خودرویی که برگه کارشناسی دارد، در همان رکورد موجودی فیلد `inspection` را مانند نمونه‌ی هایلوکس پر کنید: تعداد قطعات و موارد ساختاری، هر قطعه‌ی رنگ‌شده یا تعویض‌شده با شماره و موقعیت روی نقشه، و توضیح شاسی. صفحه جزئیات آن را به نقشه‌ی تیره‌ی شماره‌دار تبدیل می‌کند.

## اتصال به ERP (ERP-VERON)

سایت موجودی را مستقیم از ERP نمایشگاه می‌خواند (`src/erp.js`): هر خودرویی که در ERP تیک «نمایش در سایت» دارد با عکس‌ها، قیمت (به تومان)، مشخصات فنی مدل، امکانات، مدارک و برگه‌ی کارشناسی رنگ و بدنه این‌جا دیده می‌شود. اگر ERP در دسترس نباشد، همان فهرست محلی `src/inventory.js` نمایش داده می‌شود.

فرم‌ها هم به ERP می‌روند و در آن‌جا «درخواست مشتری» می‌شوند که به نوبت به کارشناس فروش سپرده می‌شود:

- صفحه‌ی هر خودرو: «با من تماس بگیرید» و «بازدید و تست خودرو»؛
- محاسبه‌ی اقساط: با شرایط خود نمایشگاه در ERP (سود ماهانه، ماه‌ها، کمترین پیش‌پرداخت) و دکمه‌ی درخواست خرید اقساطی؛
- فروش خودرو: درخواست کارشناسی و قیمت‌گذاری خودروی مشتری.

### هنگام توسعه

`npm run dev` درخواست‌های `/api` و `/files` را به ERP روی `http://localhost:8080` می‌فرستد (`vite.config.js`).
اگر ERP جای دیگری است: `ERP_PROXY=http://آدرس:پورت npm run dev`. اگر نمایشگاه یکی از محیط‌های کسب‌وکار ERP است: `ERP_HOST=automodiran.localhost:8080 npm run dev`.

### روی سرور

`deploy/Dockerfile` سایت را می‌سازد و با nginx اجرا می‌کند؛ همان nginx مسیرهای `/api` و `/files` را به ERP می‌دهد، پس سایت و ERP لازم نیست هم‌آدرس باشند و تنظیم CORS هم لازم نیست:

```sh
docker build -f deploy/Dockerfile -t automodiran-site .
docker run -d --name automodiran-site --restart unless-stopped -p 80:80 -e ERP=http://host.docker.internal:8080 -e ERP_HOST=localhost automodiran-site
```

- `ERP`: آدرسی که ERP از داخل کانتینر در آن جواب می‌دهد (روی همان کامپیوتر با Docker Desktop: `http://host.docker.internal:8080`).
- `ERP_HOST`: کدام محیط ERP (سایت اصلی: `localhost`؛ محیط جدا: مثلاً `automodiran.localhost`).
- اگر سایت روی آدرس دیگری مستقیم به ERP وصل می‌شود: هنگام ساخت `VITE_ERP_URL=https://erp.example.ir` بدهید و در ERP آن را مجاز کنید:
  `bench --site <سایت> set-config allow_cors '"https://automodiran.ir"'`
- `VITE_ERP=off` سایت را فقط با فهرست محلی می‌سازد.
